5 Encoder CPU · libx264
Encoder GPU (h264_v4l2m2m)
Usa el VideoCore del Raspberry Pi para codificar H.264 con menor carga de CPU. Compatible con overlays (logo, texto, timestamp) — el filtro corre en CPU y solo el encode final pasa a GPU.

Requiere bcm2835-codec cargado en el kernel (se configura automáticamente con make install-streaming). Si el hardware no está disponible, el sistema regresa a libx264 sin interrumpir la transmisión.
